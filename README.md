# Ethan Gibbs

I build practical software with AI assistance, from checking retail discounts to monitoring ticket availability.

I start with a decision I want software to help me make. Then I work with AI to implement the rules and check how they behave at the boundaries.

## Selected work

- **[Lantern](https://github.com/Egrocket1/lantern-match)** — A shopping assistant that checks whether two offers describe the same item before comparing prices.

- **[Kalshi Scout](https://github.com/Egrocket1/scout-odds)** — A read-only ChatGPT plugin that brings sports data and market quotes into one research workflow.

- **[Ticket Watcher](https://github.com/Egrocket1/ticket-cadence)** — A local watcher for comparing ticket listings against seat-count, price and timing constraints.

- **[Commercial Viewer](https://github.com/Egrocket1/commercial-viewer)** — A Windows application I built with AI assistance that detects commercial breaks during sports broadcasts and controls when the receiver mutes and restores sound.
